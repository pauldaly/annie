📊 Annie Forms - Dynamic Table Cell Field Placement

🎯 Table Cell Targeting Features

✅ What You Can Do:

  • Target Specific Cells - By row ID, selector, or cell index
  • Create Dynamic Rows - Add new table rows with form fields
  • Editable Data Tables - Turn static tables into forms
  • Inline Editing - Edit individual cells or entire rows
  • Action Buttons - Save/Cancel controls per row
  • Data Association - Link fields to row data
  • Multi-Cell Workflows - Coordinated field updates

📋 API Methods:

// Target specific table cell renderer.addFieldToTableCell(fieldConfig, { rowId: 'row-123', cellIndex: 2 }); // Create editable row renderer.createEditableTableRow(fields, { tableContainer: '#data-table tbody', includeActions: true, onSave: (data) => console.log(data) }); // Add multiple fields to row renderer.addFieldsToTableRow(fields, { rowSelector: 'tr[data-id="456"]', startCellIndex: 1 });

🚀 Common Use Cases

1. DataTable with Inline Editing

Transform a static data table into an editable form where users can click to edit individual cells or rows.

// Add edit field to specific cell when user clicks "Edit" renderer.addFieldToTableCell({ name: 'edit-name', type: 'text', placeholder: 'Enter name' }, { rowId: 'user-123', cellIndex: 1 // Name column }); // Replace entire row with editable fields const editFields = [ { name: 'edit-name', type: 'text', label: 'Name' }, { name: 'edit-email', type: 'email', label: 'Email' }, { name: 'edit-role', type: 'select', options: roles } ]; renderer.addFieldsToTableRow(editFields, { rowId: 'user-123', startCellIndex: 1 });

2. Dynamic Data Entry Rows

Add new rows to tables for data entry, like adding items to an invoice or creating new records.

// Create complete editable row with action buttons const newRowFields = [ { name: 'item-name', type: 'text', placeholder: 'Item name' }, { name: 'quantity', type: 'number', placeholder: 'Qty' }, { name: 'price', type: 'number', placeholder: 'Price' } ]; const newRow = renderer.createEditableTableRow(newRowFields, { tableContainer: '#invoice-table tbody', includeActions: true, onSave: (data) => { // Save to database api.createInvoiceItem(data); }, onCancel: () => { // Remove the row newRow?.remove(); } });

3. Spreadsheet-Style Editing

Create Excel-like editing experience where users can navigate between cells and edit in place.

// Add field to cell on click/focus table.addEventListener('click', (e) => { const cell = e.target.closest('td'); const row = e.target.closest('tr'); const cellIndex = Array.from(row.children).indexOf(cell); if (cell && !cell.querySelector('.annie-table-cell-field')) { renderer.addFieldToTableCell({ name: `cell-${row.id}-${cellIndex}`, type: 'text', placeholder: cell.textContent }, { rowId: row.id, cellIndex: cellIndex }); // Focus the new field const input = cell.querySelector('.annie-table-cell-field'); input?.focus(); } });

📋 Configuration Examples

Target by Row ID and Cell Index:

renderer.addFieldToTableCell({ name: 'edit-field', type: 'text', placeholder: 'Edit value' }, { rowId: 'row-123', // Target specific row cellIndex: 2 // Target third column (0-based) });

Target by CSS Selector:

renderer.addFieldToTableCell({ name: 'price-edit', type: 'number', placeholder: 'Price' }, { rowSelector: 'tr[data-product-id="456"]', // Find row by data attribute cellSelector: '.price-cell' // Find cell by class });

Create New Row with Data:

renderer.createEditableTableRow([ { name: 'new-name', type: 'text', placeholder: 'Name' }, { name: 'new-email', type: 'email', placeholder: 'Email' } ], { tableContainer: '#users-table tbody', rowData: { id: 'new-user-' + Date.now(), status: 'pending' }, includeActions: true, onSave: async (data) => { const result = await api.createUser(data); if (result.success) { // Replace with read-only row location.reload(); // Or update DOM } } });

Layout Integration:

// You can still use layout config for table cells renderer.addFieldToTableCell({ name: 'description', type: 'textarea', layout: { tableRowId: 'product-123', tableCellIndex: 3, // These properties work even in table cells: gridArea: 'description-area', // If the cell uses CSS Grid order: 2, // CSS order newRow: false // Doesn't apply to table cells } });
