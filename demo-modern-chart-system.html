🚀 Annie Framework - Modern Chart System

🏗️ Modern Architecture Overview

The new Annie chart system uses a clean, modular architecture with TypeScript, standardized interfaces, and modern D3.js patterns.

📁 src/charts/
├── 📁 base/
│   ├── 📄 chart-config.ts      ← Standardized configuration interfaces
│   ├── 📄 base-chart.ts        ← Abstract base class with common functionality
│   └── 📄 chart-utils.ts       ← Utility functions for all charts
├── 📄 pie-chart.ts             ← Modern pie chart implementation
├── 📄 bar-chart.ts             ← Bar chart (next to implement)
├── 📄 line-chart.ts            ← Line chart (next to implement)
└── 📄 chart-registry.ts        ← Chart type registry and factory

🎯 Chart Configuration Interface

Every chart uses standardized configuration with chart-specific options:

// Base configuration for all charts
interface ChartConfig {
  type: 'pie' | 'bar' | 'line' | 'scatter' | 'area';
  width?: number;
  height?: number;
  title?: string;
  subtitle?: string;
  theme?: 'light' | 'dark';
  colors?: string[];
  animated?: boolean;
  interactive?: boolean;
  responsive?: boolean;
  // ... more options
}

// Pie chart specific configuration
interface PieChartOptions {
  innerRadius?: number;       // For donut charts
  outerRadius?: number;       // Chart size
  cornerRadius?: number;      // Rounded corners
  startAngle?: number;        // Start position
  endAngle?: number;          // End position
  showLabels?: boolean;       // Show data labels
  showValues?: boolean;       // Show actual values
  showPercentages?: boolean;  // Show percentages
  labelPosition?: 'inside' | 'outside';
  explodeOnHover?: boolean;   // Interactive explosion
  // ... more pie-specific options
}

🔧 Annie Integration Example

How the modern chart system integrates with Annie's data attributes:

<!-- Simple Annie chart declaration -->
<div annie-chart="pie" 
     annie-data-source="salesData" 
     annie-chart-config="{
       title: 'Q4 Sales by Region',
       theme: 'light',
       animated: true,
       options: {
         showLabels: true,
         showPercentages: true,
         explodeOnHover: true
       }
     }">
</div>

<!-- Advanced configuration with JsonLogic -->
<div annie-chart="pie"
     annie-data-source="dynamicData"
     annie-chart-config="{
       title: 'Dynamic Chart Title',
       theme: { 'if': [{ '==': [{'var': 'userPreference'}, 'dark'] }, 'dark', 'light'] },
       colors: { 'if': [{ '==': [{'var': 'department'}, 'sales'] }, 
                        ['#007bff', '#28a745', '#dc3545'], 
                        ['#6f42c1', '#fd7e14', '#20c997']] }
     }">
</div>
