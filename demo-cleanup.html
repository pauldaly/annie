💡 Implementation Examples

Manual Component Cleanup

// Reset specific components
annie.resetComponent('datastore');  // Clear all datasets except 'store'
annie.resetComponent('observers');  // Reinitialize UI observers
annie.resetComponent('triggers');   // Reinitialize trigger handlers
annie.resetComponent('state');      // Clear state manager

// Selective element cleanup
annie.cleanupElements('.test-elements');

// Get cleanup statistics
const stats = annie.getCleanupStats();
console.log(`Active listeners: ${stats.eventListeners}`);

Memory Monitoring

// Start memory leak monitoring
annie.startMemoryMonitoring(30000); // Check every 30 seconds

// Get current memory info
const memInfo = annie.getMemoryInfo();
console.log(`Memory usage: ${(memInfo.usedJSHeapSize / 1024 / 1024).toFixed(2)}MB`);

// Force garbage collection (development only)
annie.forceGarbageCollection();

Complete Framework Cleanup

// Comprehensive cleanup and destroy
annie.destroy();

// After cleanup, all event listeners, intervals, observers are cleaned up
// All DOM elements with Annie data attributes are cleaned
// All local storage entries are cleared
// Global references are removed
