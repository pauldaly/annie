📐 Annie Forms - Bootstrap-Style 12-Column Grid Layout

🎯 Grid Layout Features

✅ What Annie Provides:

  • 12-column Bootstrap-compatible grid
  • Responsive breakpoints (xs, sm, md, lg, xl)
  • Column spans and offsets
  • Custom container targeting
  • CSS Grid areas support
  • Automatic CSS injection
  • Order control

📋 Layout Configuration:

fieldConfig.layout = { column: 6, // Span 6 columns offset: 2, // Offset by 2 columns md: { column: 4 }, // 4 cols on medium+ xs: { column: 12 }, // Full width on mobile newRow: true, // Force new row order: 2 // CSS order }

📝 Grid Layout Examples

1. Basic Column Configuration:

// Basic 6-column field renderer.addField({ name: 'firstName', type: 'text', label: 'First Name', layout: { column: 6 // Spans 6 out of 12 columns (50% width) } }); // Field with offset renderer.addField({ name: 'lastName', type: 'text', label: 'Last Name', layout: { column: 4, // Spans 4 columns offset: 2 // Skip 2 columns (creates spacing) } });

2. Responsive Breakpoints:

renderer.addField({ name: 'email', type: 'email', label: 'Email Address', layout: { column: 8, // Default: 8 columns xs: { column: 12 }, // Mobile: full width sm: { column: 10 }, // Tablet: 10 columns md: { column: 8 }, // Desktop: 8 columns lg: { column: 6 } // Large: 6 columns } });

3. Custom Container Targeting:

// Place field in specific container renderer.addField({ name: 'sidebar-info', type: 'text', label: 'Sidebar Field', layout: { containerId: 'sidebar-container', // Target specific element column: 12 } }); // Or use CSS selector renderer.addField({ name: 'header-search', type: 'search', label: 'Search', layout: { selector: '.header-search-area', // Target by selector column: 8 } });

4. Advanced Grid Features:

renderer.addField({ name: 'advanced-field', type: 'textarea', label: 'Comments', layout: { column: 8, offset: 2, // Center the field newRow: true, // Force start of new row order: 3, // CSS order for reordering gridArea: 'comments' // Named grid area (requires CSS) } });

🔄 Your Current Setup vs Annie Grid

❌ Manual Bootstrap Grid:

// You probably do something like this: <div class="row"> <div class="col-md-6"> <label>First Name</label> <input type="text" name="firstName" /> </div> <div class="col-md-6"> <label>Last Name</label> <input type="text" name="lastName" /> </div> </div> // When adding fields dynamically: function addField() { const html = `<div class="col-md-4">...</div>`; $('.row').append(html); // Manual Bootstrap class management // No responsive reconfiguration // Hard to reorder or reposition }

✅ Annie Dynamic Grid:

// Declarative configuration const renderer = new FormRenderer(form, { layout: { type: 'grid', columns: 12 } }); // Add fields with layout renderer.addField({ name: 'firstName', type: 'text', label: 'First Name', layout: { column: 6, md: { column: 4 }, xs: { column: 12 } } }); // Automatic: // ✅ Responsive classes applied // ✅ CSS Grid power + Bootstrap familiarity // ✅ Easy repositioning and reordering // ✅ Container targeting // ✅ State management integration
