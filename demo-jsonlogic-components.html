Annie JsonLogic Components Demo

Demonstrating conditional logic, loops, and dynamic classes using JsonLogic attributes.

1. JsonLogic Syntax Examples

Conditional Visibility (data-annie-if)

<!-- Simple boolean condition --> data-annie-if="true" data-annie-if="false" <!-- Variable reference --> data-annie-if="user.isActive" <!-- JsonLogic comparison --> data-annie-if='{">": [{"var": "user.age"}, 18]}' <!-- Complex logic --> data-annie-if='{"and": [{"var": "user.isActive"}, {">": [{"var": "user.loginCount"}, 5]}]}'

Dynamic Classes (data-annie-class)

<!-- Object-based conditional classes --> data-annie-class='{ "active": {"var": "user.isActive"}, "premium": {"==": [{"var": "user.plan"}, "premium"]}, "new-user": {"<": [{"var": "user.loginCount"}, 3]} }'

Loops (data-annie-for)

<!-- Simple loop --> data-annie-for="user in users" <!-- With filtering --> data-annie-for="activeUser in activeUsers"
