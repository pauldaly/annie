This example shows how to use Annie Framework animations in production with proper CSS distribution.

<script src="dist/annie.umd.min.js"></script>

📁 File Structure for Production

your-website/
├── index.html                    (this file)
├── dist/
│   ├── annie.umd.min.js         (main framework - 🔹 REQUIRED)
│   └── annie-animations.css     (animations - 🔹 REQUIRED for animations)
└── your-other-files...

Alternative Distribution Methods:

  • Auto-injection: Let Annie load CSS automatically
  • Custom path: Serve CSS from different location
  • CDN: Host both files on CDN
  • Bundled: Include in your build process
