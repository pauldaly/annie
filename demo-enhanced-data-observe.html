Enhanced Data-Observe with JsonLogic

Using your existing data-observe system enhanced with JsonLogic capabilities.

1. Enhanced data-observe Syntax

Simple User Card with Conditional Classes

{ "datasource": "currentUser", "type": "template", "template": "<h3>{{name}}</h3><p>{{email}}</p>", "jsonlogic": { "if": {"var": "isActive"}, "class": { "active": {"var": "isActive"}, "premium": {"==": [{"var": "plan"}, "premium"]} } } }

User List with Loop and Filtering

{ "datasource": "users", "type": "template", "template": "<div class='user-item'>{{name}} - {{status}}</div>", "jsonlogic": { "loop": "user in users", "if": {"var": "user.isActive"} } }

Complex Status Message with Transform

{ "datasource": "userStatus", "type": "html", "jsonlogic": { "transform": { "if": [ {"var": "isOnline"}, {"cat": ["<span class='online'>", {"var": "name"}, " is online</span>"]}, {"cat": ["<span class='offline'>", {"var": "name"}, " is offline</span>"]} ] } } }
