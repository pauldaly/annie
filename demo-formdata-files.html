📖 FormData vs JSON Comparison:

Feature FormData JSON
File Uploads ✅ Full file binary data ❌ Only filename (string)
Content-Type multipart/form-data (auto) application/json
Nested Objects Flattened with brackets Native nested structure
Arrays name[0], name[1], etc. Native array format
Server Parsing Standard form parser JSON parser required
