💻 TypeScript Implementation

Here's the actual TypeScript code that's working in this demo:

// Simple chart creation import { SimpleChart } from './charts/simple-chart'; const chart = new SimpleChart({ type: 'pie', width: 400, height: 300, title: 'Sales Distribution', theme: 'light', animated: true, showLabels: true, showTooltip: true }); const data = [ { label: 'Q1 Sales', value: 12000, color: '#007bff' }, { label: 'Q2 Sales', value: 15000, color: '#28a745' }, { label: 'Q3 Sales', value: 18000, color: '#dc3545' }, { label: 'Q4 Sales', value: 21000, color: '#ffc107' } ]; chart.render('chart-container', data);

🔧 Annie Framework Integration

The chart system integrates seamlessly with Annie's declarative approach:

<!-- HTML with Annie data attributes --> <div id="sales-chart" annie-chart="pie" annie-data-source="salesData" annie-chart-config='{ "title": "Sales by Region", "theme": "light", "animated": true, "showLabels": true }'> </div> <script> // Annie automatically processes charts on page load Annie.processCharts(); // Or create charts programmatically const chart = Annie.createChart('pie', { title: 'Revenue Distribution', width: 500, height: 400 }); </script>
