Enhanced HTTP Client Demo

This demonstrates the advanced capabilities of Annie's Enhanced HTTP Client compared to the basic ApiClient.

Basic ApiClient (Old)

  • XMLHttpRequest-based
  • Promise-based responses
  • Basic error handling
  • FormData/JSON support
  • Simple timeout handling
  • Basic validation

Enhanced HTTP Client (New)

  • Observable-based responses
  • Request/Response interceptors
  • Built-in caching system
  • Automatic retry with backoff
  • Loading state management
  • Authentication middleware
  • Response transformation
  • Advanced error handling
  • Request cancellation
  • Promise + Observable APIs

1. Observable vs Promise Responses

Enhanced HTTP Client supports both Observable and Promise patterns for maximum flexibility.

2. Request/Response Interceptors

Interceptors allow you to transform requests and responses automatically.

3. Caching System

Automatic response caching for GET requests with configurable TTL.

4. Loading State Management

Automatic loading state tracking across multiple concurrent requests.
