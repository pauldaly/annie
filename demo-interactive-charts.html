🎯 Annie Interactive Charts - Navigation & Actions

✅ This demo showcases Annie Framework's interactive chart system with navigation, actions, and element-specific interactions

🚀 Interactive Features Overview

Navigation Actions

  • URL Navigation: Direct links with parameters
  • Annie Routes: SPA navigation integration
  • Parameter Replacement: Dynamic URLs from data
  • Target Windows: _self, _blank, etc.

Popup & Modal Actions

  • Modals: Rich data detail views
  • Tooltips: Enhanced hover information
  • Sidebars: Related content panels
  • Drawers: Slide-out information

Custom Actions

  • Function Calls: Execute custom code
  • Annie Triggers: Fire framework events
  • Data Updates: Modify datasets
  • State Changes: Update application state

Analytics & Tracking

  • Google Analytics: Event tracking
  • Custom Events: Annie event system
  • User Behavior: Interaction patterns
  • Performance: Chart interaction metrics

💻 Annie Declarative Usage

How to define interactive charts using Annie's declarative syntax:

<!-- Basic interactive chart --> <div annie-chart="pie" annie-data-source="salesData" annie-chart-config='{ "title": "Sales by Region", "interactions": { "global": { "onClick": { "navigate": { "url": "/reports/region/{label}", "params": {"value": "{value}"} }, "analytics": { "event": "chart_click", "category": "sales_dashboard" } } }, "hoverEffect": {"enabled": true, "style": "explode"}, "clickEffect": {"enabled": true, "style": "pulse"} } }'> </div> <!-- Element-specific interactions --> <script> const interactiveData = [ { label: "North America", value: 45000, onClick: { navigate: { url: "/na-report" } }, onHover: { popup: { type: "tooltip", content: "<h3>North America</h3><p>Top performing region</p>" } }, contextMenu: [ { navigate: { url: "/na-details" } }, { action: { function: "exportRegionData", params: ["NA"] } } ], metadata: { growth: "+12%", manager: "Alice Johnson", lastUpdated: "2025-10-03" } } ]; </script>

🔧 Advanced Configuration Options

// Complete interactive chart configuration const config = { type: 'pie', title: 'Regional Performance Dashboard', // Visual configuration width: 500, height: 400, theme: 'light', animated: true, // Interaction configuration interactions: { // Global interactions (apply to all elements) global: { onClick: { navigate: { url: '/reports/{label}' }, analytics: { event: 'region_click', category: 'dashboard' } } }, // Visual feedback hoverEffect: { enabled: true, style: 'explode', intensity: 1.2 }, clickEffect: { enabled: true, style: 'pulse', duration: 300 }, // Behavior elementInteractions: true, // Allow element-specific overrides preventDefault: false, // Allow default browser actions stopPropagation: false // Allow event bubbling }, // Annie integration annieIntegration: { autoProcess: true, dataSource: 'regionSales', contextBindings: ['selectedRegion', 'dateRange'] } };

⚡ Action Types Reference

Navigation Actions: { navigate: { url: "/page/{label}", route: "/app/details/{value}", target: "_blank", params: { "id": "{metadata.id}", "source": "dashboard" } } }
Popup Actions: { popup: { type: "modal", template: "regionDetails", data: "{metadata}", size: "large" } }
Custom Functions: { action: { function: "window.myApp.showDetails", params: ["{label}", "{value}"], context: window.myApp } }
Annie Framework: { annie: { trigger: "regionSelected", dataUpdate: "selectedRegionData", stateChange: {"region": "{label}"}, notification: { message: "Selected {label}", type: "info" } } }
