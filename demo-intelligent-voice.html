📖 How the Intelligent Matching Works:

  1. Exact Match: Perfect text match (highest priority)
  2. Normalized Match: Ignores punctuation, case, extra spaces
  3. Fuzzy Match: Handles typos using Levenshtein distance
  4. Phonetic Match: Matches similar sounds (simplified Double Metaphone)
  5. Disambiguation: When multiple matches found, presents numbered options
