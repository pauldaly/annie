📊 Annie Chart System - The Future of Data Visualization

Declarative, AI-friendly charts with zero JavaScript required

🚀 Revolutionary Chart Approach

Annie transforms complex chart libraries into simple, declarative data attributes. No more JavaScript configuration!

🎯 Zero Configuration

Just add data attributes. Annie handles all the D3.js complexity behind the scenes.

🤖 AI-Friendly

AI can generate charts by writing simple HTML attributes. No JavaScript knowledge needed.

📱 Responsive by Default

All charts automatically adapt to screen size and orientation changes.

🎨 Theme Aware

Charts automatically match your application's design system and color scheme.

📈 Basic Chart Examples

Line Chart - Sales Over Time

<div data-annie-chart="line" data-source="sales-data" data-x="month" data-y="revenue" data-title="Monthly Revenue" data-height="300"> </div>
📈 Line Chart: Monthly Revenue
Data: sales-data.month → sales-data.revenue

Bar Chart - Product Comparison

<div data-annie-chart="bar" data-source="products" data-x="name" data-y="sales" data-color="category" data-title="Product Sales by Category"> </div>
📊 Bar Chart: Product Sales
Grouped by Category

Pie Chart - Market Share

🛠️ Chart Configuration Options

📊 Chart Types

data-annie-chart="line" // Line chart data-annie-chart="bar" // Bar chart data-annie-chart="pie" // Pie chart data-annie-chart="donut" // Donut chart data-annie-chart="area" // Area chart data-annie-chart="scatter" // Scatter plot data-annie-chart="histogram" // Histogram data-annie-chart="heatmap" // Heat map data-annie-chart="treemap" // Tree map data-annie-chart="sankey" // Sankey diagram

🎨 Styling Options

data-theme="light|dark|auto" // Color theme data-colors="['#ff6384', '#36a2eb']" // Custom colors data-width="800" // Chart width data-height="400" // Chart height data-margin="{'top': 20, 'right': 30}" // Chart margins data-font-size="14" // Text size data-background="#ffffff" // Background color

📈 Data Mapping

data-source="sales-data" // Dataset name data-x="date" // X-axis field data-y="revenue" // Y-axis field data-y="['sales', 'profit']" // Multiple Y series data-color="category" // Color grouping field data-size="volume" // Size field (scatter plots) data-filter="status:active" // Data filtering

🔧 Interactive Features

data-interactive="true" // Enable interactions data-zoom="true" // Allow zooming data-pan="true" // Allow panning data-brush="true" // Selection brush data-tooltip="true" // Show tooltips data-legend="true" // Show legend data-export="png,svg,pdf" // Export options
