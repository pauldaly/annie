♿ Accessibility: The Annie Animation System automatically respects the user's prefers-reduced-motion setting. When reduced motion is preferred, animations are either disabled or significantly reduced to ensure a comfortable experience for all users.

📚 Data Attribute Reference

Basic Attributes

data-annie-animate="fadeIn" data-annie-duration="300ms" data-annie-delay="100ms" data-annie-easing="ease"

Trigger Types

data-annie-trigger="onClick" data-annie-trigger="onHover" data-annie-trigger="dataChange" data-annie-trigger="stateChange" data-annie-trigger="onVisible" data-annie-trigger="validation"

Animation Names

fadeIn, fadeOut, slideUp, slideDown, slideLeft, slideRight, scaleIn, scaleOut, zoomIn, zoomOut, rotate, rotateIn, bounce, pulse, shake, wobble, swing, highlight, flash, rubber, tada, spin, breathe, invalid, valid

Advanced Options

data-annie-direction="reverse" data-annie-fill-mode="forwards" data-annie-repeat="infinite" data-annie-when="condition"
