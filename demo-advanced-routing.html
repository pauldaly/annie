Advanced Routing Overview

Annie's Advanced Routing brings enterprise-grade navigation capabilities while maintaining the framework's AI-first, declarative philosophy.

Route Parameters

Handle dynamic URLs like /user/:id with automatic parameter parsing and type conversion.

<a data-annie-route='{"path": "/user/:id"}' data-annie-params='{"id": "number"}'> User Profile </a>

Nested Routes

Create complex hierarchical navigation structures with parent-child relationships.

<div data-annie-nested-routes> <a data-annie-subroute="/stats">Stats</a> <a data-annie-subroute="/reports">Reports</a> </div>

Lazy Loading

Load JavaScript modules on-demand with configurable preloading strategies.

<a data-annie-lazy="analytics-bundle" data-annie-preload="hover"> Analytics </a>

History Management

Full browser history integration with push/replace state management.

<a data-annie-history="push" data-annie-state='{"context": "dashboard"}'> Navigate </a>

Query Strings

Handle URL query parameters with automatic parsing and state management.

<a data-annie-query='{"tab": "settings"}'> Settings Tab </a>

Navigation Events

Lifecycle hooks for analytics, validation, and custom navigation logic.

<a data-annie-on-enter="analytics.track" data-annie-on-leave="form.saveProgress"> Tracked Route </a>
Why Advanced Routing?
  • AI-Friendly: Declarative data attributes are easily understood and generated by AI
  • Performance: Lazy loading and preloading strategies optimize bundle sizes
  • Enterprise-Ready: Supports complex application architectures
  • SEO-Friendly: Proper URL structure and history management
  • Type-Safe: Parameter validation and TypeScript support

Parameter Handling

Annie automatically parses and converts route parameters:

  • Numbers: :id becomes 123 (number)
  • Strings: :name becomes "john" (string)
  • Booleans: :active becomes true/false
// Parameters are available in data store const params = annie.dataset('current-route-params'); console.log('User ID:', params[0].id); // Or via data attributes const userView = document.getElementById('user'); const params = JSON.parse(userView.getAttribute('data-annie-data-route-params'));

Lazy Loading Strategies

  • None: data-annie-preload="none" - Load only when needed
  • Hover: data-annie-preload="hover" - Preload on hover
  • Visible: data-annie-preload="visible" - Preload when visible
  • Immediate: data-annie-preload="immediate" - Preload immediately

Available Lifecycle Hooks

  • onEnter: Called when navigating to a route
  • onLeave: Called when leaving a route
  • onParams: Called when route parameters change
  • beforeNavigate: Called before navigation (can cancel)
  • afterNavigate: Called after navigation completes
